# VerifyX-57 QA App Test

This repository contains the automated test suite for the QA Training App using **Cucumber, Selenium, and Rest-Assured**.

## Prerequisites

- **Java JDK 11+**
- **Maven**
- **IDE** like IntelliJ IDEA or VS Code
- **Browser** for UI tests

## Repository
1. Clone the repository:

```bash
git clone https://github.com/ChamodiWelmilla/VerifyX-57-qa-app-test.git
```
## Setup & Running Tests

1. Navigate to the project folder

```bash
cd VerifyX-57-qa-app-test
```
2. Install dependencies

```bash
mvn clean install
```
3. Run tests

```bash
mvn test
```
